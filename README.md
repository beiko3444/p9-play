# 폴짝팡! 피구 대소동 — 플레이용 빌드

**플레이:** https://beiko3444.github.io/p9-play/

「폴짝팡!」 친구들이 먼지 대왕 군단과 겨루는 픽셀 피구 게임(프로토타입)의 완성된 파일만 올려 두는 저장소예요.
소스 코드는 비공개 저장소 p9에 있고, 여기 `index.html`은 그 빌드(`tools/web/build.mjs`)를 그대로 올린 것입니다.

- 이동: 왼쪽 패드(같은 쪽 두 번 밀면 달리기). 슛을 꾹 누르다 몸이 "삥!" 빛날 때 놓으면 스킬슛. 점프 중에도 슛·패스(점프슛).
- 키보드: 방향키/WASD(두 번: 달리기), J·Z 슛, K·X·스페이스 점프, L·C 패스·교체(슛 누른 채면 페이크), V 레트로 화면 켬/끔.
- 새 규칙: 리바운드 캐치, 콤보, 크로스파이어(외야 연결), 저스트 회피(공 뺏기), 반격, 페이크.
